# 商城商品图片前后端逻辑文档

本文档描述商城 SPU 商品图片的上传、存库（`objectName`）与展示（预签名 URL），与当前代码实现一致。

相关文档：`[用户头像功能前后端逻辑文档.md](用户头像功能前后端逻辑文档.md)`（同为 OSS + `FileStorageService` 模式）、`[star-pivot-security-使用说明.md](star-pivot-security-使用说明.md)`。

**与头像的差异**：商品图在业务表（如 SPU `images` 字段）中**只存 OSS 对象路径 `objectName`**（如 `goods/123/xxx.png`），不存带过期时间的预签名 URL；展示时再批量换取临时 URL。

## 二、后端逻辑

### 2.1 商品图片上传

**路由**：`POST /mall/goods/image/upload`（完整 URL：`/api/mall/goods/image/upload`）

**权限**：`@PreAuthorize("hasAuthority('mall:product:edit')")`

**请求**（`multipart/form-data`）：


| 参数        | 必填  | 说明                     |
| --------- | --- | ---------------------- |
| `file`    | 是   | 图片文件                   |
| `goodsId` | 否   | 编辑中的商品 ID，用于 OSS 分目录存储 |


**校验**（`GoodsImageConstants`）：


| 项        | 值                                                 |
| -------- | ------------------------------------------------- |
| OSS 分类目录 | `goods`                                           |
| 允许类型     | `image/png`、`image/jpeg`、`image/gif`、`image/webp` |
| 单张大小     | ≤ 5MB                                             |


**响应**（`FileUploadVO`）：

```json
{
  "code": 200,
  "data": {
    "objectName": "goods/1001/abc.webp",
    "displayUrl": "https://...?Expires=...",
    "permanentUrl": null,
    "presignedUrl": "https://...?Expires=..."
  }
}
```


| 字段                              | 用途                         |
| ------------------------------- | -------------------------- |
| `objectName`                    | **写入数据库** 的字段              |
| `displayUrl`                    | 上传后立即展示（私有桶为预签名 URL）       |
| `presignedUrl` / `permanentUrl` | 与 `displayUrl` 同源信息，按桶类型填充 |


### 2.2 预签名 URL（回显与列表）

商品图存库后，列表页、编辑页需将 `objectName` 转为可展示的 `img src`。

**批量接口**（推荐）：

```
POST /api/common/upload/presigned-urls
Content-Type: application/json
Body: ["goods/1001/a.png", "goods/1001/b.png"]

Response data: { "goods/1001/a.png": "https://...?", ... }
```

**单条接口**（兼容旧代码）：

```
GET /api/common/upload/presigned-url?objectName=goods/1001/a.png
```

**路径校验**：仅允许 `StoragePathValidator.isAllowedPresignedPath` 白名单内的前缀（含 `goods/`、`avatar/` 等），防止任意对象路径被换取链接。

**鉴权**：需登录（非匿名接口）；上传仍走商品编辑权限。

## 三、前端逻辑

### 3.1 组件 `spu-image-upload`

- **v-model**：`string[]`，元素为 `objectName` 列表，提交 SPU 表单时直接写入后端。
- **props**：`goodsId`（编辑时分目录）、`multiple`、`limit`（默认 10 张）。
- **上传**：`uploadGoodsImage(file, goodsId)` → 取响应 `objectName` 加入列表。
- **回显**：根据 v-model 中的 `objectName`，调用 `resolveGoodsImageDisplayUrls` 批量换预签名 URL 填充 `ElUpload` 的 `file-list`。
- **兼容旧数据**：若库中仍是完整 HTTP URL，`normalizeToObjectName` 会尝试提取 OSS 路径。

### 3.2 工具函数 `goods-image-url.ts`


| 函数                               | 说明                                       |
| -------------------------------- | ---------------------------------------- |
| `normalizeToObjectName`          | 规范化为存库用的 `objectName`                    |
| `resolveGoodsImageDisplayUrl`    | 单张解析（带内存缓存）                              |
| `resolveGoodsImageDisplayUrls`   | 批量解析，内部调用 `fetchGoodsImagePresignedUrls` |
| `getCoverDisplayUrl`             | 列表封面同步读取缓存                               |
| `clearGoodsImageDisplayUrlCache` | 登出或切换租户时可清空缓存                            |


预签名 URL 有过期时间；同一会话内用 `displayUrlCache` 减少重复请求。过期后需重新调用批量接口。

### 3.3 API 模块 `goods-image.ts`

```typescript
uploadGoodsImage(file: File, goodsId?: number)
fetchGoodsImagePresignedUrls(objectNames: string[])
```

## 四、数据流小结

```
上传：文件 → POST /mall/goods/image/upload → 返回 objectName → 写入 SPU 字段（JSON 数组或逗号分隔，依实体定义）
展示：objectName[] → POST /common/upload/presigned-urls → img src
持久化：库中仅存 objectName，不存 presignedUrl
```

---

## 五、对接检查清单

- 商品编辑菜单已配置权限 `mall:product:edit`
- OSS 环境变量已在对应 profile 配置（见头像文档 / `application-*.yml`）
- 新功能存库字段使用 `objectName`，勿存预签名 URL
- 列表/详情展示走 `resolveGoodsImageDisplayUrls` 或等价批量预签名接口
- 私有桶场景下理解预签名过期，必要时刷新页面或清缓存后重拉
